# Рабочий MVP: Vue 3 + Quasar

Минимально рабочий учебный кабинет с тремя экранами:

- **Лекции**: справа список лекций (из JSON), слева содержимое выбранной лекции.
- **Прогресс**: отображение прогресса по лекциям.
- **Редактор лекции (временный)**: вставка JSON, проверка и предпросмотр.

## Запуск

```bash
npm install
npm run dev
```

Сборка production:

```bash
npm run build
npm run preview
```

## Формат лекции

```json
{
  "id": "lecture-001",
  "title": "Новая лекция",
  "blocks": [
    {
      "type": "paragraph",
      "content": "Вводный абзац лекции. Здесь можно объяснить тему занятия."
    }
  ]
}
```

Источник данных в MVP: `src/data/lectures.json`.
