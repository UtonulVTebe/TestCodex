# TestCodex

Прототип редактора лекций на **Vue 3 + Quasar** для формирования JSON-конфига.

## Запуск

Откройте `index.html` в браузере или поднимите простой сервер:

```bash
python3 -m http.server 4173
```

Далее откройте `http://localhost:4173`.

## Что умеет прототип

- Редактирование метаданных лекции (`id`, `title`).
- Добавление и редактирование блоков:
  - `paragraph`
  - `task-1`
- Изменение порядка блоков, дублирование и удаление.
- Нормализация структуры блоков.
- Live preview итогового JSON.
- Копирование JSON в буфер обмена.
