# TestCodex

Прототип редактора лекций на **Vue 3 + Quasar** для формирования JSON-конфига.

## Структура файлов

- `index.html` — каркас страницы и подключение библиотек (Vue/Quasar) и локальных файлов.
- `styles.css` — стили интерфейса редактора.
- `app.js` — вся логика редактора + Vue-компонент + два режима preview (как выглядит лекция / JSON).

## Быстрый запуск

```bash
cd /workspace/TestCodex
python3 -m http.server 4173
```

Откройте: `http://localhost:4173`

## Как устроено формирование и предпросмотр JSON

1. В `app.js` есть реактивный объект `lecture` — это «источник правды» всей лекции.
2. Все поля формы (`id`, `title`, блоки) связаны с `lecture` через `v-model`.
3. `lectureJson` — это `computed`, который делает `JSON.stringify(lecture, null, 2)`.
4. Справа можно переключаться между режимами:
   - **Как увидит студент** — визуальный предпросмотр лекции.
   - **JSON** — технический конфиг `lectureJson`.
5. В обоих режимах обновление мгновенное, потому что данные берутся из реактивного объекта `lecture`.

## Что умеет прототип

- Редактирование метаданных лекции (`id`, `title`).
- Добавление и редактирование блоков:
  - `paragraph`
  - `task-1`
  - `task-dnd` (drag-and-drop задание)
- Drag-and-drop сортировка блоков + кнопки вверх/вниз.
- Изменение порядка блоков, дублирование и удаление.
- Нормализация структуры блоков.
- Поле `Ожидаемый ответ / ключ проверки` у `task-1` и `task-dnd`.
- Для `task-dnd` есть редактор элементов и зон (по строкам).
- Визуальный preview лекции (не в виде блоков редактора, а в виде «готового контента»).
- В режиме «Как увидит студент» для `task-dnd` работает перетаскивание элементов по зонам.
- В режиме «Как увидит студент» у `task-1` есть поле `Ваш ответ`.
- Live preview итогового JSON.
- Копирование JSON в буфер обмена.
- Сброс к начальному шаблону.
