# TestCodex

Прототип редактора лекций на **Vue 3 + Quasar** для формирования JSON-конфига.

## Структура файлов

- `index.html` — каркас страницы и подключение библиотек (Vue/Quasar) и локальных файлов.
- `styles.css` — стили интерфейса редактора.
- `app.js` — вся логика редактора + Vue-компонент + JSON preview.

## Быстрый запуск

```bash
cd /workspace/TestCodex
python3 -m http.server 4173
```

Откройте: `http://localhost:4173`

## Как устроено формирование и предпросмотр JSON

1. В `app.js` есть реактивный объект `lecture` — это «источник правды» всей лекции.
2. Все поля формы (`id`, `title`, блоки) связаны с `lecture` через `v-model`.
3. `lectureJson` — это `computed`, который делает `JSON.stringify(lecture, null, 2)`.
4. Справа в блоке **JSON Preview** выводится `lectureJson`, поэтому вы видите итог мгновенно при любом изменении.

## Что умеет прототип

- Редактирование метаданных лекции (`id`, `title`).
- Добавление и редактирование блоков:
  - `paragraph`
  - `task-1`
- Изменение порядка блоков, дублирование и удаление.
- Нормализация структуры блоков.
- Live preview итогового JSON.
- Копирование JSON в буфер обмена.
- Сброс к начальному шаблону.
