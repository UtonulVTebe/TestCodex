# TestCodex

Прототип редактора лекций на **Vue 3 + Quasar** для формирования JSON-конфига.

## Обновлённая структура проекта

- `index.html` — только каркас и подключение CDN + входного JS-модуля.
- `styles.css` — стили UI.
- `src/lectureSchema.js` — схемы блоков, фабрики, парсинг и нормализация в экспортный JSON.
- `src/main.js` — Vue-приложение, редактор, drag-and-drop сортировка блоков и student preview.

## Быстрый запуск

```bash
cd /workspace/TestCodex
python3 -m http.server 4173
```

Откройте: `http://localhost:4173`

## Реализованные типы заданий

1. **Задание с написанием ответа** (`task-text`)
2. **Задание с выбором ответа** (`task-single`)
3. **Задание с выбором нескольких ответов** (`task-multi`)
4. **Задание на сопоставление (термин — определение)** (`task-match`)
5. **Задание drag and drop** (`task-dnd`)
6. **Задание с написанием алгоритма** (`task-algorithm`)

Дополнительно есть `paragraph` для обычного контента лекции.

## Что улучшено в архитектуре

- Логика схем и сериализации отделена от UI.
- Нормализация всегда выдаёт чистый JSON без служебных полей интерфейса.
- `index.html` упрощён: вся логика загружается из модулей `src/*`.
- Поддерживается drag-and-drop для перестановки блоков и для выполнения `task-dnd` в preview студента.
